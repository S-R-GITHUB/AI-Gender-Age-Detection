# AI Gender and Age Detection Web App

A Flask + OpenCV based AI web application that detects:

- Gender
- Age

from:

- Uploaded images
- Live webcam feed

## Features

- Image upload detection
- Real-time webcam detection
- Face detection using OpenCV DNN
- Gender prediction
- Age prediction
- Flask web interface

## Technologies Used

- Python
- Flask
- OpenCV
- Deep Learning
- HTML
- Bootstrap

## Run Project

Install requirements:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
